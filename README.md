## Como contribuir

Achou um erro, um comando desatualizado ou tem uma sugestão? Contribuições são muito bem-vindas:

1. Abra uma **issue** descrevendo o problema ou a ideia; ou
2. Faça um **fork**, crie uma branch, faça sua alteração e abra um **Pull Request**.

(Sim, tudo isso está ensinado na Aula 13 do manual.)

## Por que este material existe

Este manual foi criado para fortalecer a comunidade do software livre e defender o acesso livre ao conhecimento e à tecnologia. Aprender a versionar código não deveria depender de quanto alguém pode pagar. Se ele te ajudou, passe adiante.
